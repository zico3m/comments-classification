This project focuses on analyzing and understanding audience sentiment, behavioral patterns, and interactions on YouTube using data science and machine learning techniques.

Key Objectives:
Understand audience sentiment and emotional responses through exploratory and predictive data analysis.   Identify channels and topics that trigger positive or negative engagement.   Summarize behavioral patterns for each channel (e.g., whether engagement is driven by controversy or support).   Build a machine learning model capable of automating the classification of comment sentiments.   Provide actionable insights and recommendations for content creators and decision-makers to improve engagement management.
